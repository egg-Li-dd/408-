# 408 真题管理器（含考研数学二）

一个纯前端、单文件、可离线运行的考研刷题管理器。内置 **408 计算机学科专业基础 2009–2025 共 799 题**，以及 **考研数学二 2021–2025 共 110 题**，合计 **909 题**。支持按年份 / 科目 / 知识点 / 难度 / 题型多维筛选、随机组卷、自我判分与练习记录，数学公式自动用 KaTeX 渲染。

> 直接打开 `app/408真题管理器.html` 即可使用；练习数据存在浏览器 localStorage，不上传任何服务器。

## 功能特性

- **题库浏览**：按年份、科目（数据结构 / 计算机组成原理 / 操作系统 / 计算机网络 / 考研数学二）、知识点（按科目分组）、难度、题型筛选；支持全文搜索。
- **随机刷题**：按任意标签条件组合随机组卷，选择题作答即判分，综合题自判；仅打分的记录会被保留。
- **练习记录**：统计正确率、已练题数；预置「已完成 / 需重做」快捷标签，也可自定义标签。
- **公式渲染**：数学题中的积分、求导、矩阵等公式以标准 LaTeX 书写，界面用 KaTeX 渲染。
- **图片题**：题目配图随题内嵌，点击可放大查看。
- **导入导出**：导出全部 / 筛选结果 / 练习记录 / 一键完整备份；导入 JSON 题库；可视化表单录入新题并支持上传配图。
- **零依赖单文件**：除 KaTeX CDN 外无外部依赖，桌面 / 平板 / 移动端均可使用，亦可打包为 Android APK。

## 快速开始

### 直接使用

用浏览器打开 `app/408真题管理器.html`。

> 首次打开需联网加载 KaTeX 公式字体；离线时公式以原始 LaTeX 文本显示。

### 从源码构建

题库原始数据为 `data/{年份}.json`（408）与 `math_data/{年份}.json`（数学二），图片在 `assets/`、`math_assets/`。

```bash
python build_app.py
# 生成 app/408真题管理器.html（合并题目 + 图片转 base64 内嵌）
```

## 题目数据格式

单个题目为一个 JSON 对象：

```json
{
  "id": "2024-1",
  "year": 2024,
  "type": "choice",
  "number": 1,
  "subject": "数据结构",
  "stem": "题干…，公式用 $...$",
  "options": {"A":"…","B":"…","C":"…","D":"…"},
  "answer": "D",
  "analysis": "解析…",
  "knowledge": ["链表"],
  "difficulty": "基础",
  "image": null
}
```

- `type`：`choice`=单选，`big`=综合 / 填空 / 解答。
- `subject`：数据结构 / 计算机组成原理 / 操作系统 / 计算机网络 / 考研数学二。
- 数学公式用标准 LaTeX，如 `$\int_0^1 x^2\,dx$`、`$\frac{a}{b}$`。

## 数据来源

- 408 真题与解析：考生回忆整理，扫描件转录。
- 考研数学二：高校公开真题页（2021–2025），仅用于学习交流。

## 说明与限制

- 题目内容、答案与解析忠于原卷；个别原卷印刷 / 答案疑点已在数据中标注。
- 本项目仅供个人学习使用，请勿用于商业用途。
